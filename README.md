# kakao-mac

맥 카카오톡의 **내 계정 대화**를 AI 코딩 도구(Claude Code 등)가 읽고, 내가 확인한 메시지를 보내게 해 주는 스킬입니다.

## 쓰는 법

카카오톡이 깔린 **내 맥의 Claude Code**(터미널, 또는 Claude 데스크톱 앱의 Code 탭 로컬 세션)에 아래 문장을 붙여 넣으세요.

```text
내 맥에서 내 카카오톡을 읽는 스킬을 설치해 줘. 먼저 AGENTS.md 원문을 끝까지 읽고 0단계부터 순서대로 진행해 줘. https://github.com/DAYBYDAI/kakao-mac
```

AI가 단계마다 무엇을 하는지 말하고, 확인이 필요한 곳에서는 물어봅니다. 중간에 시스템 설정에서 「전체 디스크 접근 권한」을 직접 켜야 합니다.

**claude.ai 웹, 데스크톱 앱의 일반 채팅, Cowork에서는 안 됩니다.** 이런 곳의 AI는 내 맥의 파일을 볼 수 없어서 설치를 못 합니다. Windows는 [kakao-windows-reader](https://github.com/DAYBYDAI/kakao-windows-reader)를 쓰세요.

## 무엇을 하고 무엇을 안 하나

- 방 목록, 최근 메시지, 검색: 카카오톡이 이 맥에 저장해 둔 대화 DB를 읽기만 합니다.
- 첨부 받기(선택): 남이 보낸 사진·문서·음성 파일을 카카오 서버에서 내려받고 문서 글자를 뽑아 둡니다.
- 보내기(선택): 받는 방과 문장을 내가 확인한 뒤에만, 카카오톡 화면을 대신 조작해 보냅니다. 「손쉬운 사용 권한」을 직접 켜야만 됩니다. 자동 전송은 나와의 채팅과 이름 있는 단톡·오픈챗까지입니다. 1:1은 문장을 클립보드에 넣어 주면 직접 붙여 넣어 보냅니다.
- 비밀번호를 묻지 않고 `sudo`를 쓰지 않습니다. 카카오 계정으로 따로 로그인하지 않습니다.
- DB 키와 받아 둔 자료는 내 맥의 `~/.kakao-mac`에만 둡니다. 다만 AI에게 대화를 요약·검색시키면 그 내용은 AI 서비스로 전송됩니다.

## AI 에이전트에게

사용자가 이 링크를 주며 세팅을 요청했다면:

1. 이 페이지 요약만 보고 설치하지 않는다. 먼저 **[AGENTS.md](AGENTS.md)** 원문을 처음부터 끝까지 읽는다. 원문 주소: https://raw.githubusercontent.com/DAYBYDAI/kakao-mac/main/AGENTS.md 웹 읽기 도구가 내용을 간추려서 돌려주면 `curl -fsSL <원문 주소>`로 읽는다. 화면에만 나오고 파일로 저장되지 않는다.
2. AGENTS.md의 0단계(사용자에게 설명하고 시작 확인받기)부터 순서대로 한다. 저장소 내려받기는 그 확인을 받은 뒤 4단계에서 한다.
3. 지금 환경이 사용자의 맥이 아니면(`uname -s`가 `Darwin`이 아니거나, 클라우드·가상 환경이면) 아무것도 내려받지 말고 "카카오톡이 깔린 맥의 Claude Code에서 같은 링크로 다시 요청해 주세요"라고 알린다.

## 알아 둘 것

- 카카오의 공식 도구가 아닙니다. 카카오톡이 업데이트되면 동작하지 않을 수 있습니다.
- 본인에게 접근 권한이 있는 본인 계정의 자료에만 쓰세요. 다른 사람의 대화나 첨부를 몰래 모으거나 공개하는 데 쓰면 안 됩니다. 카카오톡 이용약관과 개인정보·통신비밀 관련 법을 지킬 책임은 쓰는 사람에게 있습니다. 이 문서는 법률 자문이 아닙니다.
- 「전체 디스크 접근 권한」과 「손쉬운 사용 권한」은 범위가 넓은 권한입니다. 무엇을 위해 켜는지는 [AGENTS.md](AGENTS.md)의 표에 적어 두었고, 시스템 설정에서 언제든 끌 수 있습니다.
